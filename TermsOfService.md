This Terms of Service applies to the Job Tracker application ("the application"), a personal project built for tracking job applications by parsing Gmail messages.

### 2. What the Application Does

When run, the application connects to a user's own Gmail account via Google's OAuth authorization flow, with the user's explicit consent, to:

- Read the sender, subject, and body of emails in the user's inbox.
- Classify emails locally using a locally-hosted language model to determine if they relate to a job application the user has submitted.
- Apply a Gmail label ("JobTracker/Processed") to emails it has evaluated.
- Update a local database, maintained by the user, to reflect changes in job application status (such as interview invitations, rejections, or offers).

See the Privacy Policy for details on what data is accessed and how it is handled.
