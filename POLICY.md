## Privacy Policy

If you intend to locally-host this application, you are doing so with the knowledge that the app will be able to read and modify the contents of your Gmail inbox.

Particularly, the application will:

1. Be able to read the contents of your inbox's emails, and will extract the sender, subject, and body fields of said emails.
2. Send the extracted email contents ONLY to a locally-hosted instance of Qwen3 4B, running on the same machine. This data is not sent to any third party, cloud service, or external server.
3. Create an email label titled "JobTracker/Processed" in your Gmail account, and modify emails by applying this label to them.
4. Store extracted company, role, and application status information in a local database on the same machine, used solely to track the status of job applications submitted by the account holder.

No data collected by this application is shared with, sold to, or accessible by any third party. All processing happens locally on the host machine running the application.

Access can be revoked at any time by removing the app's permissions at [myaccount.google.com/permissions](https://myaccount.google.com/permissions).

This application is a personal project and is not intended for use by anyone other than its developer.
